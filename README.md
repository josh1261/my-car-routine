# 탄만큼

함께 탄 거리만큼, 차가 잰 실제 비용을 똑같이 나누는 Pleos Connect용 동승 정산 앱입니다.

현대자동차그룹 차량용 앱 개발 공모전 출품작입니다. (팀명 N분의1)

## 무엇을 하나요

친구, 동료, 가족을 태우고 다닐 때 "기름값(전기값) 얼마 나왔지?"를 운전자가 따로 계산하지 않아도 됩니다.

- 기어를 P에서 바꾸면 계산을 시작합니다.
- 차가 잰 계기판 누적 거리와 실제 에너지 사용량을, 그 구간에 타고 있던 사람 수(운전자 포함)로 나눠 각자에게 쌓습니다.
  - 전기차: 배터리 잔량(kWh)이 줄어든 만큼 × 운전자가 정한 전기 단가(원/kWh)
  - 내연기관: 달린 거리 ÷ 차가 잰 연비(km/L) × 운전자가 정한 연료 단가(원/L)
- 중간에 누가 타면 그때부터 함께 나누고, 누가 내리면 그 사람이 탄 거리만큼의 몫을 바로 화면과 음성으로 알려 줍니다.
- 통행료·주차비는 정차 중에 버튼으로 넣으면 그때 타고 있던 사람끼리 나눕니다.
- “지금 얼마야”, “정산해 줘”라고 말하면 음성으로 금액을 알려 주고 정산을 마칩니다.
- 운전자가 자기 송금 링크(예: 토스 아이디 링크)를 저장해 두면 금액 옆에 QR 코드로 보여 줍니다. 앱은 돈을 직접 주고받지 않습니다.

금액은 10원 단위로 반올림합니다. 앱은 이익을 붙이지 않고 실제로 든 비용만 나눕니다.

## 사용하는 차량 신호 (모두 읽기 전용)

| 용도 | API |
| --- | --- |
| 달린 거리 | Vehicle SDK `Odometer` 누적 주행 거리 |
| 전기차 에너지 사용량 | Vehicle SDK `EvBattery` 배터리 잔량, 최대 용량 |
| 내연기관 연비 | Vehicle SDK `Fuel` 현재 연비 |
| 탑승 인원 | Vehicle SDK `Seat` 좌석 탑승(조수석, 뒷좌석 왼쪽·오른쪽) |
| 주행 시작·정차 | Android Automotive `GEAR_SELECTION` |
| 음성 | SpeechToText, TextToSpeech SDK (ON_DEVICE) |

차를 제어하는 기능은 없습니다. 설정 변경과 통행료 추가, 정산은 기어가 P일 때만 할 수 있습니다.

## APK 위치

`apk/N분의1_탄만큼_release.apk`를 사용합니다. 시연 영상은 `demo/탄만큼_시연.mp4`입니다.

## 테스트 환경

- Pleos Connect Emulator v2.1.0 (Android 14, API 34, 전기차 설정)
- Vehicle SDK 2.3.2, SpeechToText SDK 3.3.1, TextToSpeech SDK 3.3.1
- 실차에서는 시험하지 않았습니다.

## 실행 방법

### APK 설치

```bash
adb install apk/N분의1_탄만큼_release.apk
```

앱을 설치하거나 업데이트한 뒤에는 에뮬레이터를 재부팅해 주세요. 재설치 직후에는 좌석 탑승 신호 응답이 오지 않는 경우가 있었습니다.

### 주행 상황 만들기

```bash
adb forward tcp:8088 tcp:8088
```

포워딩 후 브라우저에서 `http://127.0.0.1:8088/`을 엽니다. 콘솔 창이 열려 있어야 값이 전달됩니다.

1. Seat Occupancy에서 조수석이나 뒷좌석을 탑승으로 바꿉니다.
2. 기어를 D로 바꿉니다. 계산이 시작됩니다.
3. Odometer(누적 거리)를 늘리고 EV Battery의 Battery Energy를 줄입니다.
4. 기어를 P로 바꾼 뒤 뒷좌석을 빈 좌석으로 바꾸면 내린 사람의 몫이 나옵니다.
5. “정산 마치기”를 누르면 전체 정산이 나옵니다.

### 소스에서 빌드

JDK 17과 Android SDK Platform 35가 필요합니다.

```bash
./gradlew assembleDebug
```

release 빌드의 서명 키는 저장소에 포함하지 않았습니다. 서명 설정 파일이 없으면 서명되지 않은 APK가 만들어집니다.

## 필요한 설정

- 마이크로 말하려면 에뮬레이터의 Extended Controls > Microphone에서 오디오 입력을 켜야 합니다.
- 음성 기능은 ON_DEVICE 모드를 사용하므로 Client ID와 Client Secret이 필요 없습니다.

## 사용한 구성 요소

- Pleos Connect SDK: Vehicle, SpeechToText, TextToSpeech (42dot SDK 라이선스 적용)
- ZXing core 3.5.3 (QR 코드 생성, Apache License 2.0)
- Kotlin 표준 라이브러리와 위 SDK가 의존하는 라이브러리(각 라이선스 적용)
- Android Automotive OS `android.car` API

## 확인된 제한 사항

- 에뮬레이터에서는 내비게이션 위치가 움직이지 않아, 시연은 Virtual Console로 누적 거리와 배터리 잔량을 바꿔서 했습니다.
- 에뮬레이터 차량이 전기차라 내연기관(연비) 계산은 실행해 보지 못했습니다. 연비 값이 km/L로 온다고 보고 만들었습니다.
- 에뮬레이터에서 Vehicle SDK의 좌석 탑승 값이 빈 좌석은 `true`, 탑승은 `false`로 전달되어 반대로 해석합니다. 실차에서 다시 확인해야 합니다.
- 통행료는 공개 API로 실제 결제 금액을 읽을 수 없어 운전자가 버튼으로 넣습니다.
- 누적 거리가 한 번에 50km 넘게, 배터리 잔량이 한 번에 20kWh 넘게 바뀌면 값 초기화나 오류로 보고 계산에서 뺍니다.
- 시연 영상에서 음성은 음성 파일로 입력했고, 안내 소리는 영상에 담기지 않았습니다.
- 이전 출품 준비안(내 차 루틴)의 코드는 이 저장소의 첫 커밋에 남아 있습니다.
